\chapter{製作}
\section{真空注型}
\begin{enumerate}
	\item \hyperlink{label_mold}{型}を準備する。
	\begin{enumerate}
		\item 型を清掃する。
		\item \hyperlink{label_mold_spacer}{スペーサ}と\hyperlink{label_mold}{型}を 2 枚の\hyperlink{label_mold_shell}{押さえ板}で挟み、%
			\hyperlink{label_mold_clamp}{クランプ}で固定する。
			\begin{itemize}
				\item 押さえ板の上面と型の上面を一致させるため、上面を下にして組み立てる。%
					これは\hyperlink{label_vaccuum_chamber}{真空槽}に複数の型を縦に積む場合に、%
					\hyperlink{label_mold_separator_grill}{落し蓋}が型を押さないようにするためである。%
					この工夫により型の変形を防ぐ。
				\item クランプの締め付けは程々にする。%
					具体的には、組み立てた型を手で持った時、型内部の空洞の容積がほぼ変化しない程度の強さでクランプする。%
					型内部の空洞の容積が変化すると沸騰槽と型内部で樹脂の移動が起こり、意図しない気泡の巻き込みが起こりやすくなるからである。%
					\hyperlink{label_deforming}{脱泡}の操作が台無しになる。%
					またクランプの締め付けが強すぎると、型の製品となる面の肌が変形し品質を損なう。
			\end{itemize}
	\end{enumerate}
	\item 真空ポンプを準備する。
	\begin{itemize}
		\item 真空ポンプの取扱説明書に従う。
		\item 特に、オイル量が適切か確認する。
	\end{itemize}
	\item 真空槽を準備する。
	\begin{enumerate}
		\item 空気圧ゲージを準備する。
		\begin{itemize}
			\item 空気圧ゲージの取扱説明書に従う。
			\item 特に、オイル封入型の場合内圧を大気圧と一致させる為のプラグが付いているので、忘れずに操作する。
		\end{itemize}
		\item 真空槽の大気側給気口に\hyperlink{mold_capillary}{キャピラリ}を取り付ける。キャピラリの全てのバルブを閉位置にする。
		\item 真空槽の真空ポンプ側給気口と真空ポンプを接続する。真空槽の全てのバルブを閉位置にする。
	\end{enumerate}
	\item \hyperlink{link_resin}{樹脂}を準備する。
	\begin{enumerate}
		\item \hyperlink{link_scale}{秤}を\hyperlink{link_silicone_mat}{シリコーン樹脂マット}の上に設置する。
		\item \hyperlink{link_stirrer}{攪拌棒}と\hyperlink{link_disposable_cup}{プラスチックカップ}を清掃する。
		\item プラスチックカップの風袋を量る。
		\item プラスチックカップに樹脂の主剤を所定の量量り取る。
		\begin{itemize}
			\item 注型する型の個数 $ \times $ 7.1g の主剤を用いる。
		\end{itemize}
		\item プラスチックカップに\hyperlink{label_pigment}{色素}を入れる。
		\begin{itemize}
			\item 主剤 1 g に対して 1 滴の色素を用いる。
		\end{itemize}
		\item プラスチックカップに樹脂の硬化剤を入れる。
		\begin{itemize}
			\item 本製品で使用している樹脂の場合、主剤 10g に対して 4g の硬化剤を入れる。
		\end{itemize}
		\item 攪拌棒を用いて撹拌する。
		\begin{itemize}
			\item 3 分程度撹拌する。
			\item 撹拌中、気泡が入っても問題ない。真空引きしたとき結局発泡するので、撹拌時点で混入する気泡は気にする必要ない。
		\end{itemize}
	\end{enumerate}
	\item 型の沸騰槽に樹脂を入れる。
	\begin{itemize}
		\item \hyperlink{label_syringe}{注射器}を用いて 7mL 量る。
	\end{itemize}
	\item 型を真空槽に仕込む。
	\begin{itemize}
		\item 上下に 2 段積む場合、上下段の間に落とし蓋を入れる。
	\end{itemize}
	\item 真空注型を行う。
	\begin{enumerate}
		\item 真空槽に蓋を設置する。
		\item 真空ポンプのオイル量と、真空槽の真空ポンプ側バルブが閉位置になっている事を確認し、真空ポンプのを稼働させる。
		\item 真空槽の真空ポンプ側バルブを開位置にする。
		\item 真空槽の蓋を押さえつけて気密する。
		\item ストップウォッチで計時開始する。
		\item 空気圧ゲージがゲージ圧で -1 bar となるか、または 3 分経過するまで待機する。
		\item キャピラリの 2 つのバルブがどちらも閉位置になっている事を確認し、真空槽の大気側バルブを開位置にする。
		\begin{itemize}
			\item この操作はキャピラリ内圧と真空槽内圧を等しくするためのもの。
		\end{itemize}
		\item 真空槽の真空ポンプ側バルブを閉位置にする。
		\item 真空ポンプを停止する。
		\item キャピラリの\hyperlink{label_syringe_needle_red}{注射針}が付いている側のバルブを開位置にする。
		\item 空気圧ゲージがゲージ圧で -0.7 bar となるまで待機する。
		\item 真空槽の大気側バルブを閉位置にする。
		\item キャピラリの注射針が付いている側のバルブを閉位置にする。
		\item キャピラリの注射針が付いていない側のバルブを開位置にする。
		\item 真空槽の大気側バルブを少しだけ開き、槽内を大気圧まで戻す。
		\begin{itemize}
			\item 戻す速度は適当。-0.7 bar から 0 bar まで 1 分程度で大気圧となればよい。速すぎると槽内が結露するので結露しない程度であればよい。
		\end{itemize}
		\item 操作したバルブを全て閉位置に戻す。
	\end{enumerate}
	\item 脱泡を行う。
	\begin{enumerate}
		\item この操作は、型の上部に引き込まれた気泡を取り除くためのもの。
		\item 真空槽から型を取り出す。
		\item プラスチックカップに残っている樹脂を注射器に 1mL 吸い込み、\hyperlink{label_syringe_needle_pink}{注射針}を取り付ける。このとき気泡が入らないように充分注意する。
		\item シリンジを操作して注射針の中の気泡と樹脂を追い出す。樹脂が針先から 2、3 滴出る程度でよい。
		\item 真空槽の底に空いているランナー部分の穴に注射針を挿入し、樹脂を注入する。
		\begin{itemize}
			\item 1mL を 5 秒程度の速度で注入する。
			\item 注射器が空になるまで注入せず、少し手前で止める。1mL を全て注入すると、注射器の中に残っていた僅かな気泡も型内部に注入してしまうからである。
			\item 注入する操作の過程で、ランナー部分から気泡が上がってくるのでよく観察する。通常この操作は 1 回だけで充分だが、1mL を注入し終わる後半になっても気泡がまだ上がってくるようなら、何らか操作が失敗して気泡が想定より多く混入している。リカバリのため、投機的にはなってしまうが、この脱泡の操作を気泡が上がってこなくなるまで繰り返すとよいかもしれない。
		\end{itemize}
	\end{enumerate}
	\item 型を静置する。
	\begin{itemize}
		\item 平らな安定した場所で保管する。
	\end{itemize}
\end{enumerate}
