\section{脱型と仕上げ}
\chklink{label:epoxy}{エポキシ樹脂}の主剤と硬化剤を混合してから 72 時間以上経過後に脱型する。ランナー部分をカッターナイフで切り、\chklink{label:mold}{型}の合わせ面部分に樹脂のはみ出しがあれば除去する。

\section{真空注型}
\begin{enumerate}
	\item \chklink{label:mold}{型}を準備する。
	\begin{enumerate}
		\item 型を清掃する。
		\item \chklink{label:mold_spacer}{スペーサ}と\chklink{label:mold}{型}を 2 枚の\chklink{label:mold_shell}{押さえ板}で挟み、%
			\chklink{label:mold_clamp}{クランプ}で固定する。
			\begin{itemize}
				\item 押さえ板の上面と型の上面を一致させるため、上面を下にして組み立てる。%
					これは\chklink{label:vacuum_chamber}{真空槽}に複数の型を縦に積む場合に、%
					\chklink{label:mold_separator_grill}{落し蓋}が型を押さないようにするためである。%
					この工夫により型の変形を防ぐ。
				\item クランプの締め付けは程々にする。%
					具体的には、組み立てた型を手で持った時、型内部の空洞の容積がほぼ変化しない程度の強さでクランプする。%
					型内部の空洞の容積が変化すると\chklink{label:boiling_tank}{沸騰槽}と型内部で樹脂の移動が起こり、意図しない気泡の巻き込みが起こりやすくなるからである。%
					\chklink{label:deforming}{脱泡}の操作が台無しになる。%
					またクランプの締め付けが強すぎると、型表面の肌が変形し品質を損なう。
			\end{itemize}
	\end{enumerate}
	\item 真空ポンプを準備する。
	\begin{itemize}
		\item 真空ポンプの取扱説明書に従う。
		\item 特に、オイル量が適切か確認する。
	\end{itemize}
	\item 真空槽を準備する。
	\begin{enumerate}
		\item 空気圧ゲージを準備する。
		\begin{itemize}
			\item 空気圧ゲージの取扱説明書に従う。
			\item オイル封入型の場合内圧を大気圧と一致させる為のプラグが付いているので、忘れずに操作する。
		\end{itemize}
		\item 真空槽の大気側プラグに\chklink{label:mold_capillary}{キャピラリ}を取り付ける。キャピラリの全てのバルブを全閉にする。
		\item 真空槽の真空ポンプ側プラグと真空ポンプを接続する。真空槽の全てのバルブを全閉にする。
	\end{enumerate}
	\item \chklink{label:epoxy}{エポキシ樹脂}を準備する。
	\begin{enumerate}
		\item \chklink{label:scale}{秤}を\chklink{label:silicone_mat}{シリコーン樹脂マット}の上に設置する。
		\item \chklink{label:stirrer}{攪拌棒}と\chklink{label:disposable_cup}{プラスチックカップ}を清掃する。
		\item プラスチックカップの風袋を量る。
		\item プラスチックカップにエポキシ樹脂の主剤を所定の量量り取る。
		\begin{itemize}
			\item 注型する型の個数 $ \times $ 7.1g の主剤を用いる。
		\end{itemize}
		\item プラスチックカップに\chklink{label:pigment}{色素}を投入する。
		\begin{itemize}
			\item 主剤 1.0 g に対して 1.0 滴の色素を用いる。
		\end{itemize}
		\item プラスチックカップにエポキシ樹脂の硬化剤を投入する。
		\begin{itemize}
			\item 主剤の重量の 40\% の硬化剤を投入する。
		\end{itemize}
		\item 攪拌棒を用いて撹拌する。
		\begin{itemize}
			\item 3 分程度撹拌する。
			\item 撹拌中、気泡が入っても問題ない。真空引きしたとき結局発泡するので、撹拌時点で混入する気泡は気にする必要ない。
		\end{itemize}
	\end{enumerate}
	\item 型の沸騰槽に樹脂を入れる。
	\begin{itemize}
		\item \chklink{label:syringe}{注射器}を用いて 7mL 量る。
	\end{itemize}
	\item 型一式を真空槽に仕込む。
	\begin{itemize}
		\item 上下に 2 段積む場合、上下段の間に落とし蓋を入れる。
	\end{itemize}
	\item 真空注型を行う。
	\begin{enumerate}
		\item 真空槽の蓋のパッキン部分を清掃し、真空槽に設置する。
		\item 真空ポンプのオイル量と、真空槽の真空ポンプ側バルブが全閉になっている事を確認し、真空ポンプを稼働させる。
		\item 真空槽の真空ポンプ側バルブを全開にする。
		\item 真空槽の蓋を押さえつけて気密する。
		\item ストップウォッチで計時開始する。
		\item 空気圧ゲージがゲージ圧で -1.0 bar となるか、または 3 分経過するまで待機する。
		\item キャピラリの 2 つのバルブがどちらも全閉になっている事を確認し、真空槽の大気側バルブを全開にする。
		\begin{itemize}
			\item この操作はキャピラリ内圧と真空槽内圧を等しくするためのもの。
		\end{itemize}
		\item 真空槽の真空ポンプ側バルブを全閉にする。
		\item 真空ポンプを停止する。
		\item キャピラリの\chklink{label:syringe_needle_red}{注射針(24G)}が付いている側のバルブを全開にする。
		\item 空気圧ゲージがゲージ圧で -0.7 bar となるまで待機する。
		\item 真空槽の大気側バルブを全閉にする。
		\item キャピラリの注射針が付いている側のバルブを全閉にする。
		\item キャピラリの注射針が付いていない側のバルブを全開にする。
		\item 真空槽の大気側バルブを少しだけ開き、槽内を大気圧まで戻す。
		\begin{itemize}
			\item -0.7 bar から 1 分程度で大気圧まで戻す。速すぎると槽内が結露するので結露しない程度の速度であればよい。
		\end{itemize}
		\item 操作したバルブを全て全閉に戻す。
	\end{enumerate}
	\item 脱泡を行う。\label{label:deforming}

	この操作は、型の上部に引き込まれた気泡を取り除くために行う。
	\begin{figure}[htbp]
		\centering
		\img{./img/bubble.jpeg}
		\caption{脱泡処理を行わなかった場合のランナー部周辺の様子}
		\label{fig:bubble}
	\end{figure}
	この脱泡処理を行わなかった場合の造形結果を図\ref{fig:bubble}に示す。
	本作品の形状の場合、毎回図のような位置に気泡が留まりそのまま硬化してしまうようだ。
	本処理では、ランナー部から注射器を用いて樹脂を注入し、気泡を型の外に排出する。
	\begin{enumerate}
		\item 真空槽から型一式を取り出す。
		\item プラスチックカップに残っている樹脂を注射器に 1mL 吸い込み、\chklink{label:syringe_needle_pink}{注射針(20G)}を取り付ける。このとき気泡が入らないように充分注意する。
		\item 注射器の押し子を少し押し、注射針の中の気泡を排出する。
		\item 型の沸騰槽の底に開いているランナー部分の穴に注射針を挿入し、樹脂を注入する。
		\begin{itemize}
			\item 1mL を 5 秒程度の速度で注入する。
			\item 注射器が空になるまで注入せず、少し手前で止める。1mL を全て注入すると、ガスケットに付着している気泡を型内部に注入してしまうからである。
			\item 注入する操作の過程で、ランナー部分から気泡が上がってくるのでよく観察する。
				通常この操作は 1 回だけで充分だが、注入操作の終盤になっても気泡がまだ上がってくるようなら、何らか操作が失敗して気泡が想定より多く混入している。
				リカバリのため、投機的にはなってしまうが、この脱泡の操作を気泡が上がってこなくなるまで繰り返すとよいかもしれない。
		\end{itemize}
	\end{enumerate}
	\item 型を静置する。
	\begin{itemize}
		\item 直射日光が当たらず、振動が少なく、温度の安定した場所で保管する。
	\end{itemize}
\end{enumerate}

\section{型}\label{label:mold}

\begin{figure}[htbp]
	\centering
	\img{./img/mold.jpeg}
	\caption{型の外観}
	\label{fig:mold}
\end{figure}

\begin{figure}[htbp]
	\centering
	\img{./img/mold_description.jpeg}
	\caption{型各部の呼称}
	\label{fig:mold_description}
	\label{label:boiling_tank}
\end{figure}

図\ref{fig:mold}に型の外観を示す。また型各部の呼称を図\ref{fig:mold_description}に示す。
\chklink{label:rubber}{シリコーン樹脂}で製作する。
型は 2 個一組で組み立てて使用する。
2 個の型は、同一の\chklink{label:prototype}{原型}を用いて製作し、パッキン部の凹凸のみが異なる。
組み立てた型には\chklink{label:boiling_tank}{沸騰槽}があり、沸騰槽の底はすり鉢状となっている。
沸騰槽の底には、ランナーとなる穴が一つ開いており型の空洞部と繋がっている。

以下の手順で製作する。

\begin{enumerate}
	\item \chklink{label:mold_holder}{原型ホルダ}を清掃し、原型を嵌め込む。
	原型の基準面は、原型ホルダの基準面よりわずかに埋まった位置で固定する。
	これにより、製作した型は原型周辺が僅かに盛り上がった形状となり、\chklink{label:mold_clamp}{クランプ}した時力が掛かりやすくなる。
	造形物の周囲に生じる\chklink{label:epoxy}{エポキシ樹脂}の膜を非常に薄くすることができる。
	\item 原型ホルダのパッキン部を造形するための溝に、\chklink{label:mold-holder-gasket-jig}{パッキン溝造形用治具}を装着する。パッキン部が凸のものを造形する時は、この手順は省略する。
	\item \chklink{label:mold-resevoir}{沸騰槽造形用治具}の底面に\chklink{label:double_sided_tape}{両面テープ}と\chklink{label:masking_tape}{マスキングテープ}を貼る。
	\begin{itemize}
		\item マスキングテープは、両面テープの厚み分の隙間を埋めるために貼る。
		シリコーン樹脂が隙間に侵入するのを防ぐためである。
		両面テープを沸騰槽造形用治具の底面に満遍なく貼り付ける事が容易であれば、マスキングテープは省略してもよい。
	\end{itemize}
	\item 沸騰槽造形用治具を原型ホルダに接着する。
	\item 原型ホルダに\chklink{label:mold-holder-frame}{枠}を装着する。
	\item 原型ホルダ一式を清掃する。
	\item \chklink{label:scale}{秤}を\chklink{label:silicone_mat}{シリコーン樹脂マット}の上に設置する。
	\item \chklink{label:stirring_spatula}{攪拌用ヘラ}と\chklink{label:disposable_cup}{プラスチックカップ}を清掃する。
	\item プラスチックカップの風袋を量る。
	\item シリコーン樹脂主剤をプラスチックカップに所定の量量り取る。
	\begin{itemize}
		\item パッキン部が凸のものを造形する場合は 127.5g、凹のものを造形する時は 120.7g を量り取る。
	\end{itemize}
	\item シリコーン樹脂硬化剤を所定の量投入し 3 分程度混合する。
	\begin{itemize}
		\item 量り取った主剤の重量の 3\% の硬化剤を投入する。
	\end{itemize}
	\item 適当なベニア板製の作業台の上に新聞紙を敷き、原型ホルダ一式を置く。この作業台は、硬化させる間の保管場所に移動させるためのものなので目的を達せられれば材質は何でもよい。
	\item 原型ホルダ一式の原型表面全体を薄く覆う程度に、シリコーン樹脂液を注ぐ。
	\item \chklink{label:sillicon_brower}{シリコーンブロア}を用いて原型表面のシリコーン樹脂液に空気を吹き付け、原型に付着している微小な気泡を除去する(図\ref{fig:bubble-removal})。
	\begin{itemize}
		\item 気泡が残ったままシリコーン樹脂が硬化すると、型を用いて造形した際小さな突起として現れ品質を損なう。従って気泡の除去処理は、原型の表面処理と同程度に重要である。
		\item 樹脂液を薄膜にすることにより、微小な気泡が崩壊しやすくなる。空気を吹き付けた箇所をよく観察していると、気泡が弾ける瞬間を見ることができる。
		\item 空気を吹き付ける方法の代わりに、樹脂液を刷毛で塗って薄膜を作る方法もある。洗い物が増えるので、本作品程度の大きさなら空気を吹き付ける方法の方が効率が良い。
	\end{itemize}
	\begin{figure}[htbp]
		\centering
		\img{./img/bubble-removal.jpeg}
		\caption{気泡除去を行った直後の様子}
		\label{fig:bubble-removal}
	\end{figure}
	\item 残りのシリコーン樹脂液を、枠の上面を超えるまで注ぐ。
	\item \chklink{label:plastic_plate}{下敷き}表面を清掃し、シリコーン樹脂液面に被せる。
	\begin{itemize}
		\item 下敷きは PET 製のものを用いる。塩ビ製のものは、シリコーン樹脂が固着することがある。
	\end{itemize}
	\item 硬化させるための保管場所の水平度を確認する。傾いていると、枠からはみ出した樹脂が新聞紙の範囲を越えて周囲を汚染する可能性がある。肉眼で見て分からないほどゆっくり流動するので注意が必要。
	\item 作業台一式を硬化させるための保管場所に移動する。
	\item 下敷きの上に本を置き、その上に重りを載せる。本は、枠より大判でハードカバーのものを用いる。下敷きがたわまないようにするためである。重りは、枠と下敷きが接触するまで余剰のシリコーン樹脂液を押し出すために設置する。
	\item シリコーン樹脂が硬化するまで静置する。目安は 12 時間程度。
	\item 原型ホルダから型を取り出す前に、可能な範囲でバリを取り除く。
	\begin{itemize}
		\item 硬化したシリコーン樹脂はプリプリしていて刃物が入りづらく、バリの除去が非常に面倒。原型ホルダから外す前の状態の方がバリ取り作業しやすいので、外す前に可能な範囲でバリ取り作業を行っておく。
	\end{itemize}
	\item 硬化した型を原型ホルダから取り外す。
	\item カッターナイフや彫刻刀を用いて、残っているバリを取り除く。
	\begin{itemize}
		\item 沸騰槽底のランナー部分は、バリの形状を観察してあえてバリ取りしない事がある。
			バリが僧帽弁のようになっているもののランナー穴は貫通している場合、その方がランナー部を細く造形できる。
			エポキシ樹脂で造形した時ランナー部が細い方が切り取り痕が小さくなるため都合が良い。
	\end{itemize}
\end{enumerate}

\section{キャピラリ}\label{label:mold_capillary}

\begin{figure}[htbp]
	\centering
	\img{./img/capillary.jpeg}
	\caption{キャピラリ}
	\label{fig:capillary}
\end{figure}

\chklink{label:vacuum_chamber}{真空槽}に流入する空気の流量を抑制し、注型作業の再現性を良くするために用いる。
真空注型は、真空から大気圧に戻す際のごく序盤でほとんどの樹脂が型の空洞部に流れ込むため、序盤の圧力制御は非常に重要である。
真空槽に付属のボールバルブを手動で操作する場合、流量の細かな制御が難しく再現性が低い。
キャピラリを用いることで、バルブの操作は全開/全閉を行うだけで充分な再現性が得られる。

以下の手順で製作する。

\begin{enumerate}
	\item $ \phi $10mm の\chklink{label:10mmtube}{シリコーンチューブ}を 75mm の長さに切断する。\chklink{label:valve}{三叉バルブ}とキャピラリ本体を接続するのに用いる。
	\item $ \phi $10mm のシリコーンチューブを 50mm の長さに切断する。三叉バルブと真空槽の大気側プラグを接続するのに用いる。
	\item \chklink{label:syringe}{注射器}に\chklink{label:syringe_needle_red}{注射針(24G)}を取り付ける。押し子は使用しない。
	\item 前述の長さ 75mm のシリコーンチューブを、前述の注射器のルアーロック部分に被せる。もう一方のチューブ端を三叉バルブのバルブが付いているプラグどちらかに接続する（図\ref{fig:capillary}）。
	\item 真空槽の大気側プラグに付属しているフィルタを撤去する。
	\item \chklink{label:hose_nipple9mm}{ホースニップル(G 1/4)}の雄ねじに\chklink{label:seal_tape}{シールテープ}を巻き、真空槽の大気側雌ねじに装着する。
	\item 三叉バルブのバルブが付いていないプラグと、前述のホースニップル(G 1/4)と、を前述の長さ 50mm のシリコーンチューブを使って接続する。真空槽を片付ける時は、こちらのシリコーンチューブの、三叉バルブ側の端を三叉バルブから外す。
\end{enumerate}
